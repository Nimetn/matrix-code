# DynamicSquareMatrix

Учебный проект по ООП на C++: класс для работы с динамической квадратной матрицей целых чисел нечётного размера (≥ 11). Программа находит максимум и минимум в заштрихованной области, считает диапазон и удаляет строку с максимальным элементом.

---

## Основная идея

Ключевая особенность реализации — **экономия памяти**. Под матрицу выделяется ровно столько памяти, сколько необходимо для решения задачи, без хранения избыточных данных.

Класс хранит **две матрицы одновременно**:

- `fullData` — полная матрица `Rows × Cols` (нужна для вывода и удаления строк);
- `shadedData` — «заштрихованная» область (треугольник, образованный главной и побочной диагоналями), где и производятся все вычисления.

Такое разделение позволяет:
- не пересчитывать границы области при каждом проходе по элементам;
- обрабатывать в алгоритмах поиска и подсчёта только те элементы, которые участвуют в условии, — без лишних проверок «в области ли элемент?»;
- сократить число итераций внутренних циклов на «мёртвых» зонах матрицы.

## Структура класса

| Метод | Назначение |
|---|---|
| `DynamicSquareMatrix(int n)` | Конструктор с проверкой нечётности и `n >= 11` |
| `~DynamicSquareMatrix()` | Освобождение памяти обеих матриц |
| `allocateMemory()` / `allocateConstraintMemory()` | Раздельное выделение памяти под полную и заштрихованную матрицы |
| `fillRandom(low, hi)` | Заполнение случайными числами |
| `transferToShadedMatrix()` | Копирование заштрихованной области |
| `getMax()` / `getMin()` | Максимум и минимум в заштрихованной области |
| `getRangeInShaded()` | Диапазон = max − min |
| `countElementsNearMax()` | Кол-во элементов < max − 20 % диапазона |
| `deleteRowFromFullMatrix(row)` | Удаление строки из полной матрицы |
| `rebuildShadedData()` | Перестройка заштрихованной матрицы после удаления |
| `printToConsole()` | Вывод результатов на экран |
| `saveOriginalToFile()` / `saveResultToFile()` | Вывод результатов в файл |

## Задания

1. **Класс матрицы** — конструкторы, деструктор, проверка нечётности размера, заполнение случайными числами, вывод в консоль и файл.
2. **Заштрихованная область**:
   - **a)** поиск максимального и минимального элементов;
   - **b)** диапазон = max − min; подсчёт количества элементов, меньших `max − 0.2 · диапазон`.
3. **Удаление строки**, содержащей максимальный элемент заштрихованной области.

---

## Формула заштрихованной области

Для строки `i` длина области вычисляется накопительно:

```
len = -1
для i от 0 до Rows-1:
    если i <= Rows/2: len += 1
    если i >  Rows/2: len -= 1
    длина строки в области = Cols - len
```

## Сборка и запуск (Code::Blocks, Windows)

### Требования

- ОС: Windows 10 / 11
- IDE: **Code::Blocks** (версия с MinGW, например 20.03)
- Компилятор: **MinGW-w64 (g++)**, встроенный в Code::Blocks
- Стандарт C++: **C++11** или новее

### Пошагово

1. **File → New → Project → Console application → C++**
2. Укажи имя проекта, например `Matrix`.
3. В появившемся `main.cpp` удали стандартный шаблон и вставь свой код (`matrix_code.cpp`).
4. **Build → Build and run** (или клавиша **F9**).
5. В появившемся окне консоли введи размер матрицы (нечётное, ≥ 11).

### Если консоль не показывает кириллицу

В коде уже есть:

```cpp
SetConsoleCP(1251);
SetConsoleOutputCP(1251);
```

Этого достаточно, если файл сохранён в кодировке **Windows-1251**.

Если файл в **UTF-8** — кириллица в консоли превратится в «кракозябры». Тогда:

- **Settings → Editor → General settings → Encoding** → выбери *Windows-1251* для текущего файла,
- либо пересохрани файл как Windows-1251 (**File → Save as → Encoding**).

### Файлы результатов

- `matrix.txt` — исходная матрица и результаты задания 2.
- `matrix_result.txt` — матрица после удаления строки.

Оба файла сохраняются **в папку, откуда запущена программа**. По умолчанию в Code::Blocks это:

```
Matrix/bin/Debug/matrix.exe
```

Значит и `.txt` появятся рядом с `.exe`, в `bin/Debug/`. Если хочешь — можно поменять путь в коде на абсолютный.

### Типичные проблемы

| Проблема | Решение |
|---|---|
| `'SetConsoleCP' was not declared` | Добавь `#include <windows.h>` (в коде уже есть) |
| Кракозябры в консоли | Сохрани файл в **Windows-1251** |
| `srand` даёт одинаковые числа | В коде используется `srand(time(NULL))` — числа меняются между запусками |
| Файлы не создаются | Проверь права на папку `bin/Debug/` |
